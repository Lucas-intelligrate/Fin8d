## 4. 互動規格

| 元素 | 行為 |
|------|------|
| 科目選擇器 | 可搜尋代碼/名稱；僅列出 `is_postable` |
| 借貸欄位 | 輸入借方時貸方自動清零，反之亦然 |
| 平衡指示 | 即時計算；不平衡時送審按鈕 disabled |
| 關帳按鈕 | 檢查未通過時 disabled + tooltip |
| 表格排序 | 點欄位標題切換 asc/desc |
| 快捷鍵 | `Ctrl+S` 存草稿、`Ctrl+Enter` 送審 |

# Fin8d 功能需求規格（Phase 1）

**文件編號**：FR-001  
**版本**：1.0

---

## 需求編號規則

`FR-{模組}-{序號}` — 模組代碼：AUTH、MD（主檔）、GL（總帳）、RPT（報表）、SYS（系統）

---

## AUTH — 認證

| ID | 需求 | 優先級 | 驗收條件 |
|----|------|--------|----------|
| FR-AUTH-01 | 使用者以 Email + 密碼登入 | P0 | 正確帳密取得 Session；錯誤顯示提示 |
| FR-AUTH-02 | 登出 | P0 | Session 清除，導向登入頁 |
| FR-AUTH-03 | 密碼重設（Email） | P1 | 寄送重設連結，一次性 token |
| FR-AUTH-04 | Session 逾時 | P1 | 閒置 8 小時自動登出 |

---

## MD — 主檔管理

### 會計科目（Chart of Accounts）

| ID | 需求 | 優先級 | 驗收條件 |
|----|------|--------|----------|
| FR-MD-01 | 科目樹狀維護（新增/編輯/停用） | P0 | 最多 4 層；停用科目不可新分錄 |
| FR-MD-02 | 科目類型（資/負/權/收/費） | P0 | 類型影響報表歸類 |
| FR-MD-03 | 統制/明細標記 | P0 | 統制科目禁止過帳 |
| FR-MD-04 | 科目搜尋與篩選 | P1 | 依代碼、名稱、類型篩選 |

### 幣別與匯率

| ID | 需求 | 優先級 | 驗收條件 |
|----|------|--------|----------|
| FR-MD-05 | 幣別主檔（代碼、名稱、小數位） | P0 | 預設 TWD |
| FR-MD-06 | 匯率表（日期、幣別、匯率） | P1 | 支援歷史匯率查詢 |
| FR-MD-07 | 本位幣設定 | P0 | 公司參數指定，不可刪除 |

### 銀行帳戶

| ID | 需求 | 優先級 | 驗收條件 |
|----|------|--------|----------|
| FR-MD-08 | 銀行帳戶 CRUD | P1 | 關聯會計科目（銀行存款） |
| FR-MD-09 | 帳戶啟用/停用 | P1 | 停用後不可選為分錄對象 |

### 部門

| ID | 需求 | 優先級 | 驗收條件 |
|----|------|--------|----------|
| FR-MD-10 | 部門 CRUD | P1 | 可選填於傳票分錄 |
| FR-MD-11 | 部門樹狀（可選 2 層） | P2 | 上層部門彙總 |

### 客戶 / 廠商（往來對象）

| ID | 需求 | 優先級 | 驗收條件 |
|----|------|--------|----------|
| FR-MD-12 | 客戶主檔 CRUD | P1 | 統編、名稱、聯絡方式 |
| FR-MD-13 | 廠商主檔 CRUD | P1 | 同上 |
| FR-MD-14 | 對象可關聯預設會計科目 | P2 | Phase 2 帳款用 |

## GL — 總帳 / 傳票

| ID | 需求 | 優先級 | 驗收條件 |
|----|------|--------|----------|
| FR-GL-01 | 傳票新增（多行分錄） | P0 | 至少 2 行；每行：科目、借/貸、金額、摘要 |
| FR-GL-02 | 借貸平衡即時檢核 | P0 | 不平衡時禁止存檔/送審 |
| FR-GL-03 | 傳票狀態流轉 | P0 | 草稿→送審→核准；可退回、作廢 |
| FR-GL-04 | 傳票類別 | P1 | 一般、調整、結帳等 |
| FR-GL-05 | 傳票查詢 | P0 | 日期、編號、科目、狀態、摘要 |
| FR-GL-06 | 傳票分錄輔助欄位 | P1 | 部門、幣別、匯率、原幣金額 |
| FR-GL-07 | 關帳期間鎖定 | P0 | 已關帳期間不可異動 |
| FR-GL-08 | 傳票附件（PDF/圖片） | P2 | Phase 1 可延後 |
| FR-GL-09 | 傳票複製 | P1 | 複製為新草稿 |
| FR-GL-10 | 批次核准 | P2 | 主管一次核准多張 |

### 傳票狀態定義

| 狀態 | 說明 | 可編輯 |
|------|------|--------|
| draft | 草稿 | 是 |
| pending | 待審 | 否（可撤回） |
| approved | 已核准 | 否 |
| void | 作廢 | 否 |

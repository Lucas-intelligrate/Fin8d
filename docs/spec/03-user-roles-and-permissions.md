# Fin8d 使用者角色與權限

**版本**：1.0

---

## 1. 預設角色

| 角色 | 代碼 | 說明 |
|------|------|------|
| 系統管理員 | `admin` | 全功能 + 使用者管理 + 反關帳 |
| 財務主管 | `finance_manager` | 審核傳票、關帳、報表、主檔 |
| 會計人員 | `accountant` | 傳票登打、查詢、報表（唯讀關帳） |
| 唯讀 | `viewer` | 僅查詢報表與傳票 |

---

## 3. 資料列級規則

- Phase 1 為**單一公司**，無多租戶
- 使用者僅能存取所屬公司資料
- 已關帳期間：所有角色均不可修改該期間傳票（反關帳後除外）

---

## 4. API 授權

- 所有 API（除 `/auth/login`）需 Bearer JWT
- 權限以 `role` claim 檢查 middleware
- 403 回應含 `{ "error": "FORBIDDEN", "required_role": "..." }`

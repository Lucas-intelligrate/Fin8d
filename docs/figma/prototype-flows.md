# Fin8d Figma Prototype 連線

設定 **Starting Frame** 為各 Phase 的入口，以下為核心 happy path + 關鍵分支。

---

## Phase 1 主流程

```
AUTH / 登入 / 正向
  → [登入] → AUTH / 儀表板
  → [新增傳票] → GL / 傳票登打 / 正向
  → [送審] → GL / 送審核准
  → [核准] → GL / 傳票詳情 / 已核准
  → [試算表] → RPT / 試算表
  → [關帳] → SYS / 月結關帳
  → [確認關帳] → SYS / 關帳成功
```

### Phase 1 負向分支
| 從 | 觸發 | 到 |
|----|------|-----|
| 登入 / 正向 | 登入（錯誤密碼） | 登入 / 失敗 |
| 傳票登打 | 借貸不平送審 | 借貸不平衡 |
| 傳票登打 | 關帳期存檔 | 關帳期間 |
| 送審核准 | 無權限核准 | 核准 / 被阻擋 |
| 任意 | 403 | 權限不足 |

---

## Phase 2 主流程

```
P2-AR / 應收憑單列表
  → [新增] → 新增憑單 → [儲存] → 憑單詳情
  → [收款] → 收款登錄 → [下一步] → 收款沖銷 → [確認] → 應收憑單列表

P2-AP / 應付憑單列表
  → [付款] → 付款登錄
  → [請款] → 請款單 → [審核] → P4-APR / 簽核詳情（跨 Phase）
```

### Phase 2 負向
| 從 | 到 |
|----|-----|
| 收款沖銷 / 超額 | P2-AR / 超額沖銷 |
| 付款 / 未核准 | P2-AP / 付款阻擋 |

---

## Phase 3 整合流程（最重要）

```
P3-SAL / 銷售訂單
  → [銷貨] → 銷貨單
  → [預覽應收] → P2-AR / 憑單詳情
  → [開立發票] → P3-INV / 銷項發票

P3-PUR / 採購訂單
  → [進貨] → 進貨單
  → [預覽應付] → P2-AP / 憑單詳情
  → [進項發票] → P3-INV / 進項發票

P3 / 整合流程圖（總覽頁，各區塊連到上述 Frame）
```

---

## Phase 4 主流程

```
P4-APR / 待辦簽核
  → [審核] → 簽核詳情
  → [核准] → 回到待辦（或 P2 付款）
  → [退回] → 簽核退回

P4-FA / 資產清冊
  → [折舊] → 折舊作業
  → [年度結轉] → 年度結轉

P4-BUD / 預算執行
  → [超支請款] → 超支阻擋
```

---

## Prototype 設定提示

1. **Interaction：** On click → Navigate to → Frame
2. **Animation：** Instant（wireframe 階段不需動效）
3. **Starting points：** 每個 Page 設一個（例如 P1 從「登入 / 正向」）
4. **Overlay 錯誤：** 負向狀態可用 Replace 或 Navigate，保持一致即可
5. **Present 連結：** Share → Copy link，給團隊試流程

Phase 1 靜態原型 · 各模組正向／負向流程對應 · 規格見 docs/spec/flows/

1. 認證與權限 (AUTH)

正向

  • 登入AUTH-01
  • 申請重設密碼AUTH-02
  • 登入後儀表板AUTH-03
  • 首次設定精靈AUTH-04

負向

  • 登入失敗AUTH-01 ✗
  • 重設連結失效AUTH-02 ✗
  • 權限不足AUTH-03 ✗

2. 主檔資料 (MD)

正向

  • 會計科目表MD-01
  • 新增／編輯科目MD-01
  • 幣別MD-02
  • 往來對象MD-03
  • 部門MD-04
  • 銀行帳戶MD-05

負向

  • 科目驗證失敗MD-01 ✗

3. 傳票與總帳 (VOU / GL)

正向

  • 傳票列表VOU-01
  • 新增傳票VOU-01
  • 傳票詳情（草稿）VOU-01
  • 送審／核准VOU-02
  • 已核准傳票VOU-02
  • 已作廢傳票VOU-05

負向

  • 借貸不平衡VOU-01 ✗
  • 已關帳期間VOU-01 ✗
  • 核准被阻擋VOU-02 ✗

4. 報表 (RPT)

正向

  • 試算表RPT-01
  • 資產負債表RPT-02
  • 損益表RPT-03
  • 科目明細帳RPT-04

負向

  • 無資料／查詢無結果RPT ✗

5. 系統 (SYS)

正向

  • 系統設定SYS-01
  • 新增使用者SYS-02
  • 月結關帳SYS-03
  • 關帳成功SYS-03
  • 稽核日誌SYS-04

負向

  • 關帳前檢查失敗SYS-03 ✗（同頁警示）
  • 系統錯誤（通用）全域
